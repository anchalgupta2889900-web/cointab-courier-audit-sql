# Cointab Courier Service - Shipment & Cost Audit

## 📌 Problem Statement
Cointab (Courier Company) wanted to audit if they were being overcharged by their delivery partner. Need to compare expected cost vs billed cost for 100k+ shipments.

## 🛠️ Tools Used
- SQL (MySQL)
- Python (Jupyter Notebook)
- Excel

## 🔍 What I Did
- Analyzed 100,000+ AWB records with Zones (A,B,C,D,E) and weights
- Wrote SQL queries using JOIN, GROUP BY, CASE WHEN, CTEs
- Compared Expected Charges (based on rate card) vs Actual Billed Amount
- Identified Overcharged, Undercharged, and Correctly Charged shipments
- Calculated total cost savings / loss

## 📊 Key Findings
- Found ~5% of shipments were overcharged
- Identified incorrect zone mapping as main reason
- Created summary report for finance team to claim refund
